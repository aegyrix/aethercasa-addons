# ÆtherCasa Home Assistant Add-ons

Official add-on repository for [ÆtherCasa](https://aethercasa.app).

## Install

Follow the step-by-step install guide at
**<https://aethercasa.com/docs>** — it covers the Home Assistant add-on path
(HAOS / Supervised) and the Docker path (HA Container / Core), including how to
add this add-on repository to your Add-on Store.

Once installed, start the add-on and open its **Log** tab: it prints an
activation URL and a short code to approve in the ÆtherCasa app. No pairing
code or long-lived token needs to be entered by hand.

## Available add-ons

- **[ÆtherCasa Bridge](./aethercasa-bridge/README.md)** — streams entity
  state from this HA instance to your ÆtherCasa home and relays commands.
