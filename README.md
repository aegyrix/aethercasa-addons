# AetherCasa Home Assistant Add-ons

Official add-on repository for [AetherCasa](https://aethercasa.app).

## Add this repository to Home Assistant

1. Open your Home Assistant instance → **Settings → Add-ons → Add-on Store**.
2. Click the ⋮ menu → **Repositories**.
3. Paste `https://github.com/aegyrix/aethercasa-addons` and click **Add**.
4. The **AetherCasa Bridge** add-on will appear in the store.

## Available add-ons

- **[AetherCasa Bridge](./aethercasa-bridge/README.md)** — streams entity
  state from this HA instance to your AetherCasa home and relays commands.
